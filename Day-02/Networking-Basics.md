# Day 02 — Networking Basics

## 🎯 Objective
To understand how devices communicate in a network and the role of IP addresses.

## 🔹 Description
In this module, I learned the basics of networking, including what a network is, how devices communicate, and how IP addresses are used to identify devices.

## 🔹 What is a Network
A network is a group of connected devices that communicate with each other to share data and resources.

## 🔹 IP Address
An IP address is a unique identifier assigned to each device in a network, used to send and receive data.

## 🔹 Types of IP Address
- Public IP → Used on the internet  
- Private IP → Used within local networks  

## 🔹 My Understanding
From this module, I understood that devices communicate using IP addresses. When a user enters a website name, DNS converts it into an IP address, which helps the device locate the destination server. After that, communication takes place through the client-server model, where the client sends a request and the server responds.
I also understood that networking is important because it forms the foundation of how systems communicate and exchange data.
This understanding will help me analyze network activity and logs in a SOC role.

## 🔹 Real-Life Example
When I open a website, my device sends a request using its IP address to the server, and the server responds back with the requested data.
